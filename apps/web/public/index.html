Q-Tape

Post-quantum publishing authority for TapeOut DeWEB sites. 只读状态与普通钱包持有者操作；浏览器不导入、不接触 Falcon 私钥。

先在本地运行 qtape vault prepare ... --json，把输出中的 data.transaction 粘贴到下面。浏览器只负责用普通钱包提交；Falcon KeyProof 在本地 signer 生成。

粘贴 qtape release plan 生成的 plan JSON。核验会要求两家独立 RPC 在同一区块读回文件长度、字节 SHA-256 与 manifest。
